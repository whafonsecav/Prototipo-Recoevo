Antes de fabricar

  • El prototipo de corte láser es una caja con uniones dentadas. Al pisar el pedal derecho, una barra con dientes hace girar el eje con 13 cuchillas sin filo.
  • Los planos no compensan el grosor del corte del láser: si las uniones quedan flojas, se pegan; si quedan duras, se lijan.
  • Los STL vienen de un modelo hecho para presentar, no para fabricar: conviene revisar el grosor de las paredes antes de imprimir.
  • Este prototipo todavía no se ha armado: cualquier ajuste que nos recomienden es bienvenido.
